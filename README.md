# Markdown

Highlighting for Markdown files, and a preview of the rendered page.

- **Open Preview** (`Ctrl+Shift+V`) shows the active Markdown document, rendered, in a tab.
- **Open Preview to the Side** (`Ctrl+K V`) shows it beside the editor.

The preview follows the document as you type. It shows headings, lists, task lists, tables,
code (highlighted in languages Ferrite knows), links, and pictures from the document's folder.
Links to other files open them; links to headings scroll there. Pictures on the web aren't
loaded, and HTML is shown as its text.

Ferrite uses the same renderer for extensions' READMEs, like this one.
